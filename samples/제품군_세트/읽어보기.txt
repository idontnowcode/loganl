서로 다른 제품군 5개 시험 로그 — Local Log Analyzer

모두 가상 데이터입니다. 실제 장비의 로그 형식, 오류 코드의 뜻, 동작 사양이 아닙니다.
(이름은 모두 TEST-, 코드는 TEST-E### 형식이고 뜻이 없습니다.)

■ 왜 만들었나
처음 만든 samples/새형식_시험_50은 줄 모양(10가지 형식)만 다르고, 이벤트 이름·동작 흐름·고장 방식은
모두 같은 '가상 제품 하나'였습니다. 그래서 그 세트의 검출률은 한 제품군에만 맞춘 값이었습니다.
이 세트는 제품군마다 로그 양식·구성요소·이벤트 이름·동작 구조·값 항목·고장 방식을 모두 다르게 했습니다.

■ 제품군(폴더마다 정상 40 + 비정상 10, 답은 폴더의 정답표.txt)
  P1 사이클 반복형  ISO 시각 + 레벨        시작 → 초기화 → (동작·점검) 반복 → 정지 → 요약
  P2 통신 세션형    JSON Lines             열기 → 인사 → 인증 → (블록 전송·응답) 반복 → 마침 → 닫기
  P3 단계 공정형    탭 내보내기(초 단위)   레시피 → 6단계마다 (진입 → 측정 3~5번 → 나감) → 완료
  P4 주기 측정형    BSD syslog(연도 없음)  1초마다 채널 4개 측정, 5주기마다 보고
  P5 동시 작업 큐형 logfmt                 작업들이 섞여 진행(접수 → 작업자 시작 → 완료), 작업자 3명

■ 비정상(제품군마다 10가지, 모두 다름)
  P1 오류 반복 후 중단, 기록 끊김, 45초 공백, 범위 밖 값, 순서 뒤바뀜, 재시도 폭증, 재시작 반복, 준비 응답 없음, 치명 오류+덤프, INFO 속 오류 코드
  P2 CRC 오류 재전송, 블록 응답 하나 빠짐, 인증 전 전송, 60초 멈춤, 응답 시간 급증, 중간 끊김, 같은 응답 9번, 인증 실패, 길이 0 블록, 전송 없이 끝남
  P3 단계 하나 통째로 없음, 단계 반복(재작업), 측정값 계속 오름, 400초 공백, 앞 단계 끝나기 전 다음 단계 시작, 경보 후 중단, 보류 경고 7번, 레시피 불일치 경고, 기록 끊김, 측정값 멈춤
  P4 채널 하나 끊김, 값 튐, 값 멈춤, 90초 공백, 읽기 오류, 보고 없음, 잡음 경고 8번, 값이 점점 오름, 시작 실패 반복, 모든 값 0
  P5 작업 하나 끝나지 않음, 대기 줄 늘어남, 작업자 멈춤, 느린 작업, 120초 멈춤, 재시도 10번, 작업자 하나 없음, 완료 두 번, 작업 거절, 완료가 시작보다 먼저
  오류 코드가 없는 미묘한 고장(작업 하나가 끝나지 않음, 값이 멈춤, 순서만 바뀜 등)을 일부러 섞었습니다.

■ 다시 만들기·재기
  uv run python samples/make_product_family_samples.py [--seed 숫자] [--out 폴더]
  uv run python samples/evaluate_detection.py samples/제품군_세트/P1_사이클반복형      (제품군 하나)
  uv run python samples/evaluate_detection.py samples/제품군_세트/P1_… samples/제품군_세트/P2_… …   (여러 제품군을 한 데이터에 섞어서)
  재는 방법: 정상의 1/4을 남기고 나머지만 '정상'으로 학습 → 남긴 정상과 비정상을 AI 없이 분석, 4번 반복.
  비정상은 '비정상 의심' 이상이면 검출, 남긴 정상이 그렇게 나오면 오탐.

■ 결과(2026-11-18, AI 없이 결정론 분석만)
  처음(파서만 보강): P1 100% · P2 60% · P3 60% · P4 70% · P5 50% (오탐 0~2%)
  규칙 보강 후, 이 폴더(작업용 씨앗):   P1 100% · P2 100% · P3 100% · P4 100% · P5 98%  → 199/200, 오탐 0/200
  처음 보는 씨앗(31415)으로 새로 만든 세트: P1 100% · P2 92.5% · P3 100% · P4 100% · P5 100% → 197/200, 오탐 0/200
  위 세트의 5개 제품군을 한 데이터에 섞어서(제품군마다 정상 절반만 학습): 99/100, 오탐 0/200
  남은 약점: 아주 짧은 로그(예: 블록 없이 6줄로 끝난 세션)는 비교할 근거가 적어 가끔 놓칩니다.

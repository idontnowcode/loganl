CT 유사 가상 로그 세트 (100개) — 2026-11-22

이 로그들은 시험용 가상 데이터입니다. 실제 장비(특정 제조사 CT 포함)의 로그 형식·오류 코드의 뜻·동작 사양이 아닙니다.
일반적인 CT 개념(갠트리 회전, 환자 테이블=베드 구동, X선 발생·노출, 콜리메이터, 디텍터 영상 획득, 재구성, 냉각)을
역할 이름으로만 빌렸고, 이름은 모두 TEST-, 오류 코드는 TEST-E###, 숫자는 가상 값입니다.
만든 프로그램: samples/make_ct_like_samples.py (씨앗 20261122, 다시 만들면 같은 파일이 나옴)

■ 구성
- 정상 64개: 검사 56개 + 일일 점검(QA) 8개
- 비정상 36개
- 파일 이름으로는 정상/비정상을 알 수 없습니다. 답은 정답표.txt
  (칸: 파일 · 구분 · 동작 메모(예) · 판단 가이드(예, 비정상만)). 로그 입력 탭에 그대로 옮겨 적어도 됩니다.

■ 구성요소(가상)
TEST-SYS(검사 흐름) · TEST-GANTRY(회전) · TEST-BED(베드: H=수평, V=상하) · TEST-HVG(X선 발생·노출) · TEST-TUBE(튜브 열)
TEST-COLL(콜리메이터) · TEST-DET(디텍터 영상 획득) · TEST-RECON(재구성) · TEST-COOL(냉각)

■ 검사 한 번의 흐름(가상)
시작 → 자체 점검 → (가끔) 튜브 워밍업 → 베드 올리기(V) → 촬영 위치로 이동(H)
→ 스카우트 촬영(갠트리 고정, 베드 이동하며 노출·프레임 획득) → 본 촬영 1~3번 → 재구성 → 원위치 복귀(H) → 내리기(V) → 끝
본 촬영 방식(가상 이름):
- 나선(TEST-MODE-HELICAL): 갠트리 회전 + 베드 연속 이동 + 연속 노출, 회전마다 ROT_DONE
- 축(TEST-MODE-AXIAL): 한 바퀴 노출 → 베드 한 단계 이동(STEP_MOVE/STEP_DONE) → 반복
- 동적(TEST-MODE-DYNAMIC): 베드 고정, 같은 위치에서 정해진 간격으로 반복 노출
정상에도 있는 것: 작은 베드 추종 오차 경고(FOLLOW_ERR_WARN, 오류로 안 이어짐), 냉각 팬 조정 경고,
조작자 일시 정지(OPERATOR_PAUSE, 시간이 길어짐). 경고가 있다고 비정상은 아닙니다.

■ 비정상 36개
1) 베드 구동 오류 TEST-E310 — 15개. 로그에는 같은 메시지가 남습니다:
   FAULT code=TEST-E310 TEST-BED motion fault axis=… pos_mm=… target_mm=…
   하지만 시퀀스의 다섯 위치에서 따로 나고, 위치마다 앞뒤 흐름과 결과가 다릅니다(위치마다 3개).
   - 환자 올리기(베드 상하, axis=V): 촬영 시작 전 검사 중단(SESSION_ABORT stage=TEST-STAGE-LOAD)
   - 스카우트 촬영 중 수평 이동: 노출 강제 종료·프레임 획득 중단. 3개 중 1개는 다시 촬영해 정상 종료(SERIES_RETRY)
   - 축 촬영 단계 이동 사이: 노출이 꺼진 상태에서 남, 남은 단계 취소
   - 나선 촬영 연속 이동 중: X선 노출 중에 남, 노출·획득 강제 종료
   - 촬영 뒤 원위치 복귀: 촬영은 모두 끝났고 베드를 수동으로 풀어야 함(MANUAL_RELEASE_REQUIRED)
   오류 앞에는 추종 오차 경고가 1~3번 커지며 나옵니다(정상의 작은 경고와 비교해 보세요).
2) 베드 위치 오차 — 3개. 오류 메시지 없음. 축 촬영 STEP_DONE의 err_mm 또는 나선 촬영 POS의 dev_mm이 평소보다 큼
3) 베드 통신 끊김 TEST-E320 — 2개(환자 올리기 직후 1, 나선 촬영 시작 전 1). 같은 베드지만 코드가 다름
4) 갠트리 회전 속도 미달 TEST-E210 — 3개(검사 2, 일일 점검 1)
5) X선 아크 TEST-E420 — 3개(나선 2 중 1개는 다시 노출해 끝남, 축 1)
6) 튜브 열 대기 — 2개. 오류 코드 없음. HEAT_HIGH 경고 뒤 냉각 대기 2~4분(검사 시간이 김)
7) 디텍터 프레임 손실 TEST-E510 — 3개(나선·축·스카우트). 검사는 끝나지만 재구성에서 보간
8) 디텍터 온도 이상 TEST-E520 — 2개(일일 점검 실패)
9) 재구성 멈춤 TEST-E610 — 2개(40%에서 반복 후 시간 초과)
10) 로그 끊김 — 1개(나선 촬영 노출 중에 끝남, 마무리 줄 없음)

■ 써 보는 방법(예)
- 로그 입력 탭: 정상 몇십 개를 정상으로 저장, 비정상 몇 개를 판단 가이드와 함께 저장
- 신규 로그 분석 탭: 나머지를 끌어 놓고 분석 → 왼쪽 목록의 '분석 결과', '예상 에러 메시지' 칸 확인
- 같은 TEST-E310이라도 어느 단계(적재·스카우트·축·나선·복귀)에서 났는지 근거와 AI 의견이 구분하는지 보세요.
